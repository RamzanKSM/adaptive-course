# Диагностический тест по Java — MVP

## Общие правила

- Тест предназначен прежде всего для студентов, которые никогда не программировали или никогда не работали с Java.
- Все вопросы имеют 4 варианта ответа и один правильный ответ.
- Внутри каждого блока вопросы идут от самых простых к более сложным.
- Диагностика не засчитывается как практическое освоение навыка. Она только определяет, с какого места начинать обучение.
- Неправильные ответы не уменьшают уровень навыка.
- На этапе диагностики LLM-подсказки отключены.

# Интерпретация диагностики

Диагностика нужна только для определения стартовой точки обучения.

Она **не увеличивает счётчик практического освоения навыка**.

По каждому блоку оцениваем долю правильных ответов:

- **0–40%** — тему нужно начинать с самого начала;
- **41–79%** — есть частичное понимание, тему всё равно нужно пройти;
- **80–100%** — есть достаточная начальная база, можно переходить дальше.

Для студентов с очень низким результатом сложные блоки можно не показывать полностью. При этом несколько контрольных вопросов из следующих блоков всё равно полезно оставить, чтобы не пропустить студента с фрагментарными знаниями.

# Закрепление навыков после диагностики

Диагностика и реальное освоение навыка — разные вещи.

Навык считается освоенным только после **трёх отдельных итераций закрепления на разных уроках**.

## Одна итерация

Одна итерация считается успешной, когда студент на одном уроке успешно решает **3 разные практические задачи**, проверяющие этот навык.

Неправильные попытки не уменьшают прогресс. Учитываются только успешные решения.

Пример:

```text
FOR_LOOP

Урок 4:
  задача A ✓
  задача B ✓
  задача C ✓
→ итерация 1/3 завершена

Урок 7:
  задача D ✓
  задача E ✓
  задача F ✓
→ итерация 2/3 завершена

Урок 11:
  задача G ✓
  задача H ✓
  задача I ✓
→ итерация 3/3 завершена

FOR_LOOP → MASTERED
```

Таким образом, для полного освоения навыка требуется **9 успешных практических решений**, распределённых минимум по трём разным урокам.

Повторные итерации должны происходить не подряд в рамках одного занятия, а через некоторое время. Точный интервал для spaced repetition можно определить позже.

Рекомендуемые состояния навыка:

```text
NOT_STARTED
IN_PROGRESS
REPETITION_1_COMPLETE
REPETITION_2_COMPLETE
MASTERED
```

Задачи внутри разных итераций должны быть разными, чтобы студент подтверждал понимание навыка, а не запоминал конкретное решение.
