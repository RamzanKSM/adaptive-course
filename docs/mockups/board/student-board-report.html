    1 Собери программу · Чётные числа

    ✓ верно

    Напечатай все чётные числа от 2 до n через пробел.

    Твоя программа
    int n = in.nextInt();
for (int i = 1; i <= n; i++) {
    if (i % 2 == 0) {
        System.out.print(i + " ");
    }
}

    Программа собрана верно, лишнюю строку ты не использовала.

    2 Исправь ошибку · Сумма массива

    ✓ верно

    Программа должна напечатать сумму элементов nums. Для {3, 5, 7} ожидается 15.

    Твой исправленный код
    for (int i = 0; i < nums.length; i++) {
    sum += nums[i];
}

    Все проверки пройдены.

    3 Напиши код · Гласные в строке

    ◐ частично верно

    Прочитай строку и напечатай, сколько в ней гласных a e i o u (большие и маленькие). Hello World → 3.

    Твой код
    String line = in.nextLine();
int count = 0;
for (char c : line.toCharArray()) {
    if ("aeiou".indexOf(c) >= 0) {
        count++;
    }
}
System.out.println(count);
    Пример из условия пройден, скрытый тест 3 из 4 — нет. Подумай, какие строки твоя программа считает неверно.

    Правильные решения здесь не показываются — эти задачи ещё могут встретиться тебе на уроках. Разбери их с преподавателем или в чате с помощником.

    Твой код

    Пример из условия не пройден.
    ожидалось
